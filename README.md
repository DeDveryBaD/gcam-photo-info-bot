# GCam Photo Info Bot

Telegram-бот для извлечения технических метаданных фотографии. Интерфейс и отчёты на русском языке.

## Что делает

- Принимает изображения, отправленные как Telegram-фото или как файл/документ.
- Показывает в чате: модель смартфона, данные о модуле камеры, зум, ISO, выдержку, дату/год и имя файла.
- Отправляет `report.txt` с краткой сводкой и полным выводом ExifTool.
- Отправляет `metadata.json` с полным набором полей, которые смог прочитать ExifTool.
- Отправляет копию файла, который фактически получил бот.
- Считает SHA-256 полученного файла для проверки его идентичности.
- Не выдумывает отсутствующие значения; сообщает, если поле не найдено.

## Важные ограничения

1. **Предпочтительно отправлять оригинал как файл.** Telegram может перекодировать обычные фотографии и убрать часть EXIF. Бот не может вернуть метаданные, удалённые до получения файла.
2. **«Модуль камеры» не всегда есть в метаданных.** Иногда доступны только LensModel/LensID или фокусное расстояние. Эти сведения не всегда позволяют установить физический сенсор.
3. **Зум не всегда записывается.** Бот использует явные поля DigitalZoomRatio/ZoomRatio. Фокусное расстояние и эквивалент 35 мм показывает как дополнительную информацию, но не выдаёт их за точный коэффициент зума.
4. Полный отчёт может содержать и другие приватные поля, включая GPS-координаты, серийные номера или дату/время. Не публикуйте отчёт без проверки.
5. Используется официальный Telegram Bot API. Ограничения скачивания файлов зависят от Bot API; стандартный сервер обычно позволяет боту скачивать файлы до 20 MB. Параметр `MAX_FILE_MB` намеренно задаёт собственный лимит по умолчанию 20 MB.
6. Поддержка конкретного RAW/HEIC формата зависит от установленной версии ExifTool.

## Быстрый запуск через Docker (рекомендуется)

### 1. Создайте бота

- Откройте Telegram и найдите `@BotFather`.
- Выполните `/newbot`, задайте имя и username.
- Скопируйте токен. Не публикуйте его и не отправляйте третьим лицам.

### 2. Настройте проект

В каталоге проекта:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен:

```dotenv
TELEGRAM_BOT_TOKEN=123456:your_real_token
MAX_FILE_MB=20
KEEP_TEMP_FILES=false
LOG_LEVEL=INFO
```

### 3. Запустите

Требуется Docker Engine с Compose:

```bash
docker compose up -d --build
docker compose logs -f
```

Откройте бота в Telegram и отправьте `/start`. Для остановки:

```bash
docker compose down
```

## Запуск без Docker

Требуется Python 3.11+ и ExifTool в системном PATH.

- Ubuntu/Debian: `sudo apt-get update && sudo apt-get install -y libimage-exiftool-perl`
- macOS с Homebrew: `brew install exiftool`
- Windows: установите ExifTool с официального сайта и убедитесь, что `exiftool` доступен в PATH.

Далее:

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell:
# .venv\Scripts\Activate.ps1

pip install -r requirements.txt
cp .env.example .env
# внесите токен в .env
python -m bot.main
```

## Проверка результата

1. Сначала отправьте JPEG/DNG как **файл**, а не как фото.
2. Сверьте основные поля с оригиналом в ExifTool.
3. Отправьте ту же картинку как обычную фотографию и сравните, какие поля остались.
4. Проверьте снимки с нескольких устройств и GCam-модов: наличие MakerNotes и поля зума зависит от модели и приложения камеры.

## Безопасность и приватность

- Временные файлы обрабатываются во временном каталоге и удаляются после ответа; бот не ведёт базу изображений.
- `KEEP_TEMP_FILES` оставлен как зарезервированная настройка и по умолчанию выключен; бот не сохраняет файлы постоянно.
- Токен храните только в `.env`; не коммитьте `.env` в Git.
- Для публичной группы проверьте разрешения бота и то, кто сможет отправлять ему фотографии.
- Перед использованием в большой группе задайте разумный лимит размера файла и мониторьте журналы.

## Что проверить перед боевым запуском

- `docker compose up -d --build` собирается без ошибок.
- `/start` и `/help` отвечают.
- JPEG как файл даёт ожидаемые EXIF-поля.
- Фото, отправленное как Telegram-фото, получает предупреждение о возможном сжатии.
- Файл без EXIF выдаёт «Не определено», но бот не падает.
- Большой файл блокируется лимитом.
- JSON валиден и содержит все поля, возвращённые ExifTool.
